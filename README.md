# Phila Homebrew Tap

Homebrew casks for apps by [Phila](https://phila.in.th).

```sh
brew install --cask ampol-me/tap/phila-clear
```

| Cask | App |
|---|---|
| `phila-clear` | [Phila Clear](https://clear.phila.in.th): a free, review-first disk cleaner for macOS 26+ |

Phila Clear updates itself. You can also run `brew upgrade --cask --greedy phila-clear`.
